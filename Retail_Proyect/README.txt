# Proyecto de práctica SQL 

 Requisitos
- PostgreSQL instalado.
- DBeaver para ejecutar los scripts SQL.

 Cómo ejecutar el proyecto:
1. Crear una base de datos en PostgreSQL.
2. Abrir DBeaver y conectarse a la base de datos.
3. Abrir el archivo Script-2.sql.
4. Ejecutar las líneas donde se crean las tablas y donde se cargan los datos de las mismas.
5. Ejecutar los select dependiendo de que datos queremos visualizar.

Nota: ejecutar en el orden indicado para evitar errores por dependencias entre tablas.
